# Data Structures and Algorithms Practice in C

A structured collection of C programs written while learning foundational data structures, algorithms, and problem-solving techniques.

## Topics Covered

- Arrays and basic operations
- Searching and sorting exercises
- Queue implementation using arrays
- Queue implementation using linked lists
- Enqueue, dequeue, peek, display, and empty-state operations
- Pointer-based data structures

## Technologies

- C
- Standard C library
- GCC or another C compiler

## Compile and Run

```bash
gcc path/to/file.c -o program
./program
```

On Windows:

```powershell
gcc path\to\file.c -o program.exe
.\program.exe
```

## Learning Objectives

- Understand how common data structures work internally
- Practice modular functions for each operation
- Handle overflow, underflow, and empty-state cases
- Improve problem decomposition and algorithmic thinking
- Analyse time and space complexity

## Repository Organisation

Solutions are grouped by topic and question number so that each implementation can be compiled and tested independently.
